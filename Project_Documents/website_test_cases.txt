Rasoi Food Delivery WebApp - Test Cases
=======================================

Environment Setup
-----------------
1) Backend server running at http://localhost:8000
2) Frontend server running via Vite (default http://localhost:5173)
3) MongoDB connected and seeded (optional but recommended)
4) Browser geolocation permission available for map and recommendation tests


Section A: Authentication and User Management
---------------------------------------------
TC-AUTH-001
Title: User signup with valid details
Precondition: No account exists for email/mobile
Steps:
1. Open /signup
2. Enter valid full name, email, password, mobile, role User
3. Submit form
Expected:
- OTP flow is triggered
- User sees verification step and success message

TC-AUTH-002
Title: OTP verification
Precondition: OTP generated for account
Steps:
1. Open /otp-verification/:email
2. Enter correct OTP
3. Submit
Expected:
- Account becomes verified
- User can login successfully

TC-AUTH-003
Title: Login with valid User credentials
Precondition: Verified account exists
Steps:
1. Open /login
2. Enter valid email/password
3. Submit
Expected:
- Auth cookie/session is set
- User redirected to home page

TC-AUTH-004
Title: Role-based redirect after login
Precondition: Accounts exist for roles User, RestaurantOwner, DeliveryBoy, Admin
Steps:
1. Login as RestaurantOwner
2. Login as DeliveryBoy
3. Login as Admin
Expected:
- Owner goes to /owner/dashboard
- Delivery boy goes to /delivery/dashboard
- Admin goes to /admin/dashboard

TC-AUTH-005
Title: Forgot password and reset flow
Precondition: Verified account exists
Steps:
1. Open /password/forgot and request reset
2. Use reset link /password/reset/:token
3. Set new password and login
Expected:
- Password reset succeeds
- Login works with updated password

Section C: Restaurant Menu, Cart, and Checkout
----------------------------------------------
TC-ORDER-001
Title: Add food to cart and place order
Precondition: Logged in as User
Steps:
1. Open any restaurant menu page
2. Add multiple items to cart
3. Enter delivery address
4. Optionally click "Use Current Location"
5. Click "Pay & Place Order"
Expected:
- Order placed successfully
- Status starts at "pending"
- User is redirected as implemented

TC-ORDER-002
Title: Prevent checkout with empty cart
Steps:
1. Open restaurant menu page
2. Without adding items, click checkout
Expected:
- Error toast: cart is empty
- No order created

TC-ORDER-003
Title: Prevent checkout without delivery address
Precondition: Cart has at least one item
Steps:
1. Keep address blank
2. Click checkout
Expected:
- Error toast for missing address
- No order created
